# 행동특성 작성 프롬프트와 2026 기재요령 반영

## 실제 요청

실행 프롬프트 전문은 [prompts.ts](../supabase/functions/neis-behavior/prompts.ts)의 `behaviorInstruction`이다. 사용자 원문의 역할·목적·입력 우선순위·다양성·문체·분량·최종 점검을 섹션별로 유지한다. 공통 지침은 학급 요청에 한 번만 보내며 학생마다 반복하지 않는다.

- 최초 요청: 최대 60명의 익명 식별자, 선택한 특성, 교사 메모, 목표 분량을 한 요청에 포함한다.
- 응답: `rows: [{id, text}]`. 학생별 완성된 행이 도착하는 즉시 번호순 표의 해당 칸에 넣는다. 이름·출석번호는 브라우저에 남긴다. 메모에 직접 넣은 개인정보까지 자동 익명화된다는 뜻은 아니다.
- 재작성: 선택한 대상만 요청한다. 나머지 학생의 본문을 중복 비교용 `avoid`로 한 번 보내고 대상 학생의 사실로 사용하지 않게 명시한다.
- 자동 추가 호출은 없다. 교사가 중복 또는 미완료 학생만 묶어서 요청한다. 직접 수정한 문장은 자동 재작성 대상에서 제외하고 명시적으로 선택한 경우만 바꾼다.
- 설정된 기존 NEIS 작성 모델과 사용량 제한을 공유한다. `store:false`를 적용하고 원문·응답을 DB나 로그에 저장하지 않는다. 탭 메모리 보관이며 새로고침하면 초기화된다.

## 원문에서 유지·조정한 부분

| 원문 요구 | 적용 |
| --- | --- |
| 30년 경력 초등교사·NEIS 전문가 역할 | 역할과 목적에 유지 |
| 학습·긍정·부정 특성과 교사 의견 | 특성 범주와 메모로 수집. 교사 메모 최우선 |
| 학생마다 다른 시작·전개·표현 | 전문 지침 유지. 첫 단어, 공백 제외 첫 세 글자, 동일·유사 문장 검사 추가 |
| 약 400자 | 기본 400자. 교사가 200/300/400자로 선택 가능. 공식 최대 글자 수로 안내하지 않음 |
| 부정적 특성의 긍정적 발전 가능성 | 부정적 의미를 뒤집지 않으며 실천 방향과 가능성으로 서술. 실제 개선 사실은 입력에 있을 때만 서술 |
| 명사형·주어 생략·연결어 금지·금지어 | 전문 지침과 응답 검사에 적용 |
| 마크다운 없이 한 문단 | 본문에 적용. JSON은 전송 형식이며 표는 앱이 렌더링 |
| 단계마다 질문·확인 | 최신 사용자 승인인 학급 전체 한 화면 흐름으로 대체. 중복 확인 단계 없음 |
| 예시 | 원문 기록에만 보존. 금지어 '매우' 및 입력에 없는 봉사·규칙·신뢰를 추가한 예시는 실행 프롬프트에서 사용하지 않음 |

## 2026 초등학교 기재요령의 근거

사용자가 제공한 `2026 학교생활기록부 기재요령(초등학교).pdf` 161쪽 전체에서 텍스트를 검색하고 관련 장과 공통 규정을 확인했다. 아래는 **인쇄 쪽 / PDF 파일 쪽**을 구분한 위치이다. 102·104·150쪽은 실제 지면도 대조했다.

| 인쇄 / PDF 쪽 | 내용과 적용 |
| --- | --- |
| 102 / 108 | 학년 동안의 행동특성을 바탕으로 학습·행동·인성을 종합하여 학급 담임교사가 작성. 입력된 특성과 구체적인 교사 메모를 종합하고 영역을 억지로 채우지 않는다. 부정적 특성에 관한 누가기록 권장과 누가기록 방법의 학교 결정은 관찰 파일 업로드를 강제할 근거로 확대하지 않는다. |
| 104 / 110 | 학교 교육활동인 체육·예술, 교사가 관찰한 학교 계획 봉사활동의 특성은 반영 가능. 영재교육 이수 실적은 이 항목에 넣지 않는다. 학기 표기는 교사의 선택이며 모델이 추정하지 않는다. |
| 18~19 / 24~25 | 입력 금지 사항과 사실 기반 기록, 교사 확인의 원칙. 대회·수상·인증시험·가족의 사회경제적 지위 등을 생성하지 않으며 교사가 표에서 직접 편집한다. 본문에 AI 또는 초안 표기를 추가하지 않는다. |
| 27~28 / 33~34 | 작성 주체와 활용 가능한 자료, 한글·아라비아 숫자 및 영문 예외. 특성·메모 입력을 교사의 판단 자료로 취급하되 구체적인 사건을 만들어내지 않는다. |
| 30 / 36 | 명사형 종결, 특수문자·문단 구분 번호 지양. 문단 단위 줄바꿈은 가능하므로 '한 문단'은 법정 의무가 아니라 사용자 요구이다. |
| 109 / 115 | 학생 간 서술형 항목 전체 동일·뒤바뀜·누락 정정 사례. 동일 본문은 내보내기 전에 차단하고 ID 검증과 누락 표시를 적용한다. 첫 단어·첫 세 글자 금지는 별도의 사용자 품질 기준이다. |
| 150 / 156 | 초등 행동특성 및 종합의견은 시스템 입력 가능 범위 안에서 별도의 글자 수 제한이 없다. 한글 3, 영문·숫자 1, 엔터 1바이트로 표시한다. |

학교폭력 조치 등 법정 기재사항의 별도 절차(인쇄 102~103 / PDF 108~109)는 이 일반 행동특성 생성 기능으로 자동 작성·순화·삭제하지 않는다.

## 검증의 범위

규칙 검사는 ID/누락/중복·형식·금지 표현을 탐지한다. 교사 메모의 사실성이나 문장의 교육적 적절성 전체를 자동 보증하지 않는다. 근거가 적으면 분량보다 사실 보존을 우선하며 사용자가 한 표에서 편집하도록 한다. 실제 운영 API 확인과 모의 응답 검사는 별도의 검증 기록에 구분한다.
