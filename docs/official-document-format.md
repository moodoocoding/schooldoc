# 공문서 작성 서식 기준

SchoolDoc의 공문서 HWPX 출력이 따르는 기준이다. 서식은 공통 출력 계층
[src/features/officialDocument/format.ts](../src/features/officialDocument/format.ts)의 서식 프로필과 항목 기호 함수에 있다.

## 0. 구조: 계획과 출력의 분리

```text
① 계획 계층 (문서 종류별, 예: schoolDocuments/planDocument.ts)
   AI 작성·검증·근거 연결 → 초안 → 공문 문서 모델로 변환
② 공문 문서 모델 (officialDocument/model.ts)
   제목 + 항목 트리(하위 항목·표·※ 참고) + 쪽 나눔 표시. 기호·들여쓰기·글꼴은 담지 않는다.
③ 출력 계층 (officialDocument/)
   format.ts      문서 종류 목록, 서식 프로필, 항목 기호, 들여쓰기 계산, 줄 배치
   rhwpWriter.ts  rhwp로 HWPX 조판(편집 가능한 문단·표), 내용 보존·쪽 수 검사
   rhwp.worker.ts / rhwpClient.ts  브라우저 worker 실행(render·import), 취소·시간 제한
   previewFonts.ts  미리보기 SVG에 대체 글꼴 적용
```

- 새 공문서 종류는 `OFFICIAL_DOCUMENT_KINDS`에 서식 프로필과 분량을 등록하고, 해당 기능에 `초안 → OfficialDocument` 변환기를 만든다.
- 출력 계층은 문서 종류의 목차 문구를 알지 않는다. 쪽 나눔은 모델의 `pageBreakBefore`로만 지정한다.
- 항목 기호는 트리의 최대 깊이로 고른다: 4단계 미만은 편람 순서, 4단계 이상은 □ → ◦ → - → ※.

- 원본 자료: 행정안전부 「2025 행정업무운영 편람」(2025. 12. 17.). 원본 PDF는 저장소에 올리지 않고
  로컬 `docs/references/2025_행정업무운영_편람.pdf`에 둔다(`.gitignore` 대상). 아래 쪽수는 편람 본문에 인쇄된 쪽 번호다.
- 편람은 기안문의 항목 체계·띄어쓰기·표기와 서식(민원 서식) 설계 기준은 정하지만,
  계획서 같은 붙임 문서의 글꼴·장평·자간·줄간격은 정하지 않는다. 이 값은 실제 교육청 공문 첨부 문서에서 측정한 관례를 따른다.

## 1. 편람 규정

### 항목 기호(편람 51쪽, 「행정 효율과 협업 촉진에 관한 규정 시행규칙」 제2조제1항)

| 순서 | 기호 |
| --- | --- |
| 첫째 | 1., 2., 3., … |
| 둘째 | 가., 나., 다., … |
| 셋째 | 1), 2), 3), … |
| 넷째 | 가), 나), 다), … |
| 다섯째 | (1), (2), (3), … |
| 여섯째 | (가), (나), (다), … |
| 일곱째 | ①, ②, ③, … |
| 여덟째 | ㉮, ㉯, ㉰, … |

- 하., 하), (하), ㉻ 이상이 계속되면 거., 너., 더., … 순으로 표시한다.
- 필요하면 □, ○, -, · 같은 특수 기호를 쓸 수 있다. 전자적으로 입력하기 어려운 기호는 쓰지 않는다.

### 표시 위치와 띄우기(편람 52~53쪽)

- 2타 = 한글 1자, 영문·숫자 2자, 스페이스 2번.
- 첫째 항목 기호는 왼쪽 기본선에서 시작하고, 둘째 항목부터는 바로 위 항목 위치에서 오른쪽으로 2타씩 옮겨 시작한다.
- 항목이 두 줄 이상이면 둘째 줄부터는 항목 내용의 첫 글자에 맞추는 것이 원칙이다. 왼쪽 기본선에서 시작해도 되지만, 한 문서에서는 한 가지 방식만 쓴다.
- 항목 기호와 내용 사이는 1타 띄운다. 항목이 하나뿐이면 기호를 붙이지 않는다.
- 가독성을 위해 항목 사이 위아래 여백과 줄간격은 조정할 수 있다.

### 표기(편람 49쪽, 61쪽)

- 날짜: `2025. 12. 17.`처럼 연·월·일 글자를 생략하고 마침표를 찍으며 한 타씩 띄운다. 월·일 앞의 0은 쓰지 않는다.
- 시간: 24시각제, `15:20`.
- 금액: `금113,560원(금일십일만삼천오백육십원)`.
- 끝 표시: 기안문 본문의 마지막 글자에서 2타 띄우고 `끝.`. 붙임이 있으면 붙임 표시문 다음에 한다.
- 용지: A4(210mm × 297mm).

### 서식 설계 기준(참고, 편람 147쪽)

민원 서식용 기준이며 계획서 본문에는 적용하지 않는다. 일반 줄간격 130% 이상, 글자 13pt 기본, 맑은 고딕, 표의 위·아래 테두리는 검은색이고 그 외 선은 회색이다.

## 2. 실제 공문 첨부 문서 측정값

교육청에서 학교로 보낸 공문 첨부 계획서·안내 HWPX 11개(2025~2026년)를 열어
본문 글자 수 기준으로 집계했다. 원본 문서는 저장소에 넣지 않았다.

| 항목 | 관례 | 출력 적용값 |
| --- | --- | --- |
| 본문 글꼴 | 휴먼명조(11개 중 9개) | 휴먼명조 13pt |
| 본문 크기 | 15pt(기본계획류), 13pt(예방교육 계획 등) | 13pt |
| 장평 / 자간 | 100% / 0%(일부 95~97%, -5~+8%) | 100% / 0% |
| 줄간격 | 160%(일부 165~170%) | 160% |
| 문서 제목 | HY헤드라인M 15~16pt | HY헤드라인M 16pt, 가운데 |
| 용지 여백 | 좌우 20mm, 위 15mm, 아래 15mm(일부 10mm), 머리말·꼬리말 10mm | 같음 |
| 항목 체계 | 깊은 계획서는 □ → ◦ → - → ※ | 아래 규칙 |
| 둘째 줄 | 내어쓰기로 내용 첫 글자에 맞춤 | 휴먼명조 글자 폭으로 계산한 내어쓰기 |

## 3. 출력 규칙

- 계층이 4단계 미만이면 편람 순서(1. → 가. → 1) → 가) …)를 쓴다. 현재 초안은 목차 → 문단 2단계라 이 규칙을 따른다.
- 같은 단계의 항목이 하나뿐이면 항목 기호를 붙이지 않는다(편람 53쪽). 개조식(□ ◦ - ※)은 기호를 유지한다.
- 계층이 4단계 이상 필요하면 □ → ◦ → - → ※ 체계를 쓴다.
- 어느 쪽이든 하위 항목은 2타(13pt 기준 한글 1자)씩 들여 시작하고, 둘째 줄은 내어쓰기로 내용 첫 글자에 맞춘다.
- 참고 표시(예산 합계, 학교 확인 사항)는 `※`로 쓴다.
- 일정·예산 표는 휴먼명조 12pt로 하고, 머리행은 회색 바탕에 굵게, 칸 안 여백은 좌우 1mm로 한다.
- 문서 본문에는 `[초안]`이나 AI 안내를 넣지 않는다. 초안이라는 표시는 화면과 파일 이름(`…_초안.hwpx`)에 둔다.
- 휴먼명조·HY헤드라인M은 한컴 글꼴이라 배포하지 않는다. 파일에는 이 글꼴 이름을 저장하고, 미리보기 조판과 그림에는 OFL 대체 글꼴(나눔명조, 나눔고딕 Bold)을 쓴다. 한글에서 열면 줄바꿈이 미리보기와 조금 다를 수 있다.
- 13pt·160%에서는 목차 두 개 정도가 1쪽 분량이다. 넘치면 내용이나 글자 크기를 줄이지 않고 2쪽 선택을 안내한다(기본값 2쪽).

## 4. 참고한 외부 구현

- [kordoc](https://github.com/chrisryugj/kordoc)(MIT): 공문서 프리셋(기안문·보고서·계획서·통지·회의록), 기관 서식 추출,
  개조식·예산 검수, 글꼴 폭 보정을 갖춘 HWPX 도구. 단독 항목의 기호 생략과 표기 규칙 정리를 대조했다. 코드는 가져오지 않았다.
- [edunote](https://github.com/codersongpro/edunote) `geminiService.ts`의 공문서 작성기: 문서 종류별 분량 지침과 형식 우선순위
  (지정 양식 → 직접 입력 → 저장 기관 서식 → 요청문 → 표준 예시 → 기본 형식). 문서 종류 목록과 계획 계층 분리에 참고했다.
