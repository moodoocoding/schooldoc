## 2026-10-01 자료 수합 DB 최적화 수정과 실제 Chrome 재검증 (codex)

- 전용 관리 워크트리의 `codex/fix-data-collect-db-io` 브랜치에서 이전 리뷰 D01~D17 수정안을 구현했다. 공유 checkout의 main과 다른 세션의 영수증·문서 변경은 수정하지 않았다. push·PR 생성·main 병합은 하지 않았으며 이번 구현은 로컬 미커밋 상태다.
- DB 읽기는 목록 요약 20개, 현재 제출 현황 50명, 선택 이력 10개로 제한했다. 검색을 GIN 인덱스와 암호화 검색 해시 기반 DB 조건으로 옮기고, 파일 URL/메모/전체 출력 자료는 필요한 행동에서만 조회한다. 15초 소유자별 캐시·중복 요청 합치기·수동/선택 자동 갱신을 적용했다.
- 제출 확정은 새 마이그레이션의 SQL 트랜잭션으로 처리한다. 요청 UUID/내용 digest, 예약 업로드, 수합/대상 잠금, 최신 버전과 대상 상태의 원자 저장, 실패 정리/재시도 기록을 추가했다. 정리와 확정의 예약 행 경합에서도 확정된 파일을 정리하지 않도록 보완했다.
- 계정별 초안과 빠른 화면 이동 시 마지막 값 저장, 명단 없는 제출 코드/다른 탭 복구/동명이인/재제출 금지, 공통 파일 제한, 메모/이력, 최초 제출 문구, 기한 마감/연장, 검색 오류/빈 결과, 설정 명단 미리보기/실행 취소, Excel/A4/ZIP과 QR·모바일·키보드 접근성을 수정했다.
- 사용자 답변에 따라 **실제 설치 Chrome 검증을 우선**했다. Google Chrome 154.0.8037.58을 직접 실행·제어했다. 데모 앱/가상 자료로 신규 8개 + 기존 7개, 총 **15개 E2E 모두 통과**했다. 별도 headed Chrome에서 복구·재제출 금지·설정 명단·CSS 200%도 조작했다. 원격 Supabase 연동 검증으로 보고하지 않는다.
- Chrome에서 실제 파일 선택/제출·reload/코드 복구·잘못된 파일 차단과 입력 유지·대상 120명의 50/50/20 페이지·미제출 필터·설정 명단·목록 20개 페이지·기한 없음/연장/종료/재개를 확인했다. 실제 시간을 기다려 기한 마감 후 차단되고 연장 시 파일/메모가 유지되는 것도 확인했다.
- 실제 저장한 Excel·ZIP·QR·Chrome 출력 PDF를 검사했다. ZIP의 CRC/한글명/원본 바이트, Excel의 현재 상태/줄바꿈 메모, QR PNG 1024×1024, 현황 1쪽 PDF와 긴 이름 30명/4,000자 메모의 7쪽 PDF가 통과했다. Poppler로 모든 페이지를 렌더링하여 백지·겹침·잘림·여백을 확인했다. OS 인쇄 대화상자/실물 인쇄는 검사하지 않았다.
- 실제 로컬 PostgreSQL 18.4에 기존 3개와 새 1개 마이그레이션을 적용하고 동시 30명 번호, 동일 요청 8회, 동일 대상 6회, UPDATE/INSERT 실패 롤백, 파일 우회/업로드 예약/재제출 금지, 정리 경합 12회, 소유자/RLS/RPC 권한, 제한, 2,000명 검색/현재 집계 인덱스와 closed_at 유지 등을 확인했다. SQL 확인 17개와 마이그레이션 4개 모두 통과했다.
- 가상 규모에서 첫 현황 51행 JSON은 18,473 bytes, 비교용 전체 파일 9,037행 JSON은 3,961,616 bytes였다. 필드와 범위가 다른 로컬 SQL 결과이며 Supabase 디스크 I/O·egress·요금 절감률로 환산하지 않았다.
- 최종 검사: `npm run typecheck` 통과, `npm run lint` 통과(기존 다른 기능 경고 7개, 자료 수합 새 경고 0), `npm test` 59파일/477개 통과, `npm run build` 통과(기존 큰 번들 경고 유지), 두 Edge Function `deno check` 통과, `git diff --check` 통과. 제품 의존성/lockfile은 변경하지 않았다.
- 세 디자인 프로파일과 여섯 독립 AI 모의 관점의 1차 판단→2차 개발→전체 화면 재검증을 [수정 검증 보고서](../design/feature-reviews/2026-10-01-data-collect-fix/verification.md)에 기록했다. 모바일 상태 카드·공유 접기·수정본 구분·QR 경계·인쇄 포털/여백·긴 메모 별지 보완을 반영했다. 실제 전문가/교사 인터뷰·승인을 받은 것은 아니다.
- 남은 일: 시험 환경의 실제 Auth/PostgREST JSONB 검색/Storage 실패·삭제/다른 기기 갱신/학교 네트워크 부하 검증, 기존 불일치 자료의 교사 확인. DB 마이그레이션·공개/관리 Edge Functions·프런트엔드 **원격 미적용**. 원격 적용이 요청되면 이력 확인 후 DB→서버 함수→프런트엔드 순으로 반영한다.
- `../schooldoc-docs/development-history.md`와 `pro/ux-ui-expert.md`는 없어 갱신/검토했다고 보고하지 않는다. 기존 자료 수합 일지인 이 파일을 갱신했다. 검증용 Chrome·Vite·PostgreSQL은 이 작업이 시작한 세션/cluster만 종료하고 코드·증거·보고서는 보존한다.

- 전체 Chrome 15개 통과 후 공개 마감 화면에 상태 다시 확인을 보완했다. 비밀번호와 파일/메모를 유지하고 메타데이터만 명시적으로 갱신하며 주기적 DB 요청은 추가하지 않는다. 변경 후 마감/연장과 120명 현황 2개 Chrome 검사, typecheck/lint/build 및 전체 477개 단위 검사도 재통과했다.

## 2026-10-02 자료 수합 만료 요청 제한 기록 정리 (codex)

- DB 최적화의 마지막 보완으로 1시간이 지난 기술 제한 기록을 분당 한 번, 최대 1,000행씩 정리하고 시간 인덱스를 추가했다. 학생 제출 자료나 현재 제한 카운터는 삭제하지 않는다.
- 실제 PostgreSQL에 오래된 기록 2,001행을 넣어 정확히 1,000행 정리, 같은 분의 추가 호출에서 정리 없음, 현재 카운터 5 유지까지 검증했다. 최종 SQL 검사는 마이그레이션 4개와 동작 검사 18개, 총 22개 통과했다. 린트도 재통과했다.
- 전체 Chrome 15개와 후속 마감 2개, 전체 단위 477개, typecheck/build/두 서버 Deno 검사의 결과와 원격 미적용 경계는 앞 항목 및 수정 검증 보고서에 기록했다. GitHub·main·운영 배포는 하지 않았다.

- 가짜 시계 없이 실제 마감 시각을 기다렸다. 최종 실행에서 00:27:00 마감 후 00:27:00.582에 배지가 기한 마감으로 바뀌었고 읽기는 2→2로 유지됐다. 기한 없음·직접 종료 항목은 각각 수합 중·종료를 유지했다. 화면 검토에서 첫 무기한 시험 자료의 기본 기한이 남은 것을 발견해 UI로 제거하고 확인 assertion을 추가한 뒤 마감 검사 1개를 재실행해 통과했다.
- 1366×900/390×844 전체 화면을 확인하고 세 디자인 프로파일의 구현 전후 AI 모의 판단을 [검증 보고서](../design/feature-reviews/2026-10-01-data-collect-fix/verification.md)에 추가했다. 데스크톱·모바일 axe 위반 0개, 가로 넘침 없음, 브라우저 pageerror 0개. 실제 전문가·교사·스크린리더 검토는 아니다.
- 검사: 공식 typecheck 통과, lint 통과(기존 경고 7개), 전체 단위 59파일·478개 통과, build 통과(기존 큰 번들 경고 유지). 단위 검사에는 새로고침 후 다른 페이지 캐시 유지와 15초 경계 재조회도 포함했다. Chrome JSON·조회 횟수·마감 시각·전체 화면 증거를 기존 보고서 폴더에 보존했다.
