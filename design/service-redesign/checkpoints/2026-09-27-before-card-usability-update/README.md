# PC 역할 배정 사용성 재설계 전 복구 지점

2026-09-27에 현재 작업 트리의 화면 관련 파일 7개를 그대로 복사했다. `SHA256.txt`의 해시와 원본 파일 해시가 모두 일치하는 것을 확인한 뒤 재설계를 시작했다. 이 시점의 실제 화면은 [PC 전체 캡처](../../implementation-2026-09-27/role-assignment-desktop.png)에서 볼 수 있다.

`src/`와 `tests/` 아래에 원래 경로를 그대로 보존했다. 새 버전이 마음에 들지 않을 때는 이 폴더의 파일 중 **이번 재설계에서 변경한 파일만** 원래 경로로 복원한다. 다른 업무의 미커밋 변경을 지우는 `git reset --hard`는 사용하지 않는다. 복원 전에 현재 차이를 확인하고, 복원 후 타입 검사와 해당 화면의 브라우저 검사를 다시 수행한다.

이 복구 지점은 로컬 코드·테스트의 사본이다. 브라우저의 로컬 저장 데이터나 원격 DB 상태를 복원하지는 않는다.
