# 논문 검토와 PC 역할 배정 설계 근거

검토일: 2026-09-27. 웹디자인·시각 탐색·정보 구조에 관한 논문 5편의 공개 자료를 검토했다. 아래에 전문 일부와 초록 확인 범위를 구분했다. 모든 논문의 전문을 읽었다고 하거나 논문이 SchoolDoc의 성능을 입증했다고 표현하지 않는다.

사용자 지침에 따라 홈과 모바일은 유지하고 PC 역할 배정만 다시 설계한다.

## 1. Brumby & Zhuang — Visual Grouping in Menu Interfaces (CHI 2015)

[저자 소속 대학의 논문 정보](https://discovery.ucl.ac.uk/id/eprint/1499240/) · [저자 원고 PDF](https://discovery.ucl.ac.uk/1499240/1/DuncanBrumby_Visual%20Grouping_paper359final.pdf)

**확인 범위:** 4쪽 PDF의 방법·결과·논의·한계.

36명이 36개 단어 메뉴에서 특정 항목을 찾았다. 의미적으로 관련된 항목을 묶은 조건에서 탐색이 빨랐다. 시각적 경계의 효과는 의미 구조와 그룹 크기에 따라 달랐으며, 무관한 항목을 상자로 묶으면 오히려 느려졌다. 따라서 '상자를 없애면 무조건 좋아진다'거나 '그룹화는 항상 빠르다'는 결론은 아니다.

**설계 해석:** 역할을 배정 중/완료로 구분하고, 현재 담당자와 추가 후보는 서로 다른 의미 그룹으로 분리한다. 장식보다 작업 의미에 맞는 조직을 우선한다.

**한계:** 영어 단어를 한 번씩 찾는 실험이다. 교사의 반복 사용·한국어 학생 이름·배정 업무에서 같은 효과를 보장하지 않는다.

## 2. Hornof — Visual Search and Mouse-Pointing in Labeled versus Unlabeled Two-Dimensional Visual Hierarchies (TOCHI 2001)

[저자 대학 서버 PDF](https://ix.cs.uoregon.edu/~hornof/downloads/ToCHI_2001.pdf)

**확인 범위:** 참가자·절차(§7.3–7.4), 탐색 결과(§8.1), 시각 탐색 및 화면 설계 함의(§9.2·9.4).

16명의 실험에서 유용한 그룹 라벨이 있는 구조는 라벨 없는 구조보다 탐색이 빨랐다. 저자는 항목 수나 화면 밀도에 일률적인 제한을 두기보다 의미 있는 조직과 탐색 전략을 보아야 한다고 설명한다.

**설계 해석:** 설명 문장은 제거하지만 '담당 학생', '학생 추가'처럼 서로 다른 행동 영역을 구분하는 짧은 라벨은 유지한다. 필요한 정보를 전부 숨기는 극단적인 미니멀리즘으로 바꾸지 않는다.

**한계:** 인위적으로 구성한 탐색·포인팅 과제다. 이 시안의 시간 절감 수치로 환산하지 않는다.

## 3. Tuch 외 — The Role of Visual Complexity and Prototypicality Regarding First Impression of Websites (IJHCS 2012)

[Google Research의 저자·게재 정보와 초록](https://research.google/pubs/the-role-of-visual-complexity-and-prototypicality-regarding-first-impression-of-websites-working-towards-understanding-aesthetic-judgments/)

**확인 범위:** 공식 연구 페이지의 초록. 원문 연결은 열리지 않아 전문 검토로 기록하지 않는다.

웹사이트 스크린샷을 짧게 노출한 두 연구에서 시각적 복잡성과 전형성이 미적 판단에 영향을 주었다. 낮은 복잡성과 높은 전형성을 가진 화면이 좋은 평가를 받았다.

**설계 해석:** 익숙한 역할 탐색→상세→학생 선택 구조를 유지하면서, 중복 통계·진행 막대·설명 배너를 덜어낸다. 낯선 장식이나 특이한 조작법을 추가하지 않는다.

**한계:** 첫인상과 미적 평가 연구다. 실제 업무 효율이나 유료 서비스 품질을 검증한 연구로 바꿔 말하지 않는다.

## 4. Still — Web Page Visual Hierarchy: Examining Faraday's Guidelines for Entry Points (Computers in Human Behavior 2018)

[출판사 공개 초록·주요 결과](https://www.sciencedirect.com/science/article/pii/S0747563218301195)

**확인 범위:** 출판사 검색 결과의 초록·주요 결과·서지 정보. 저자 PDF와 직접 페이지 열기는 실패해 전문 검토에 포함하지 않는다.

두 시선 추적 연구에서 기존 위계 모델은 시선 진입점을 잘 예측하지 못했고, 요소 크기에 과도하게 의존하는 문제가 있었다. 위치와 구별되는 특징이 초기 주의와 관련됐다.

**설계 해석:** 제목 크기만 키우지 않는다. 선택 역할의 위치·분리된 배경·담당자와 행동의 근접성을 함께 바꾼다. 중요도가 낮은 완료 역할은 탐색 영역에서 낮은 위계로 표시한다.

**한계:** 특정 모델의 예측력에 관한 결과다. '큰 글씨가 효과 없다'거나 '이 레이아웃이 최적'이라는 주장으로 일반화하지 않는다.

## 5. Cockburn, Karlson & Bederson — A Review of Overview+Detail, Zooming, and Focus+Context Interfaces (ACM CSUR 2009)

[출판사 서지 정보](https://doi.org/10.1145/1456650.1456652) · [저자 PDF](https://www.microsoft.com/en-us/research/wp-content/uploads/2008/01/cockburn-ComputingSurveys09.pdf)

**확인 범위:** 42쪽 검토 논문의 도입, overview+detail 구분(§3), 관련 평가(§7.2.2), 요약(§8).

전체 맥락과 상세 작업을 제공하는 여러 접근을 비교한다. 전체 보기와 상세 보기를 오가는 데에도 주의 전환 비용이 있고, 어떤 방식이 유리한지는 과제에 따라 달라진다. 더 많은 개요 정보가 항상 성능을 높이지는 않는다.

**설계 해석:** 다른 역할이라는 최소 맥락은 왼쪽에 두되, 주 영역에는 선택한 역할의 담당자와 후보를 둔다. 전체 학생은 필터로 접근하게 한다. 따로 큰 총괄 진행 요약을 만들지 않는다.

**한계:** 다양한 시스템의 문헌 검토다. 이 특정 후보 필터의 우월성을 직접 실험한 근거는 아니다.

## 보조 실무 자료와 논문 구분

[Nielsen의 중복 설계에 관한 글](https://www.nngroup.com/articles/reduce-redundancydecrease-duplicated-design-decisions/)도 검색했다. 동료 심사 논문 5편에 포함하지 않았다. 이 글에서 논의하는 중복 경로·기능 문제를 모든 숫자 반복에 대한 실험 증거처럼 사용하지 않는다.

## 연구에서 시안으로 옮긴 결정

| 관찰된 문제 | 설계 결정 | 근거의 성격 |
| --- | --- | --- |
| 같은 배정 상태를 여러 숫자·문장으로 반복 | 상단 총계·진행 막대·하단 안내 삭제. 정원은 배정 중 역할 행에 1/2 한 번 | 사용자 지적 + 중복 개요의 비용에 대한 문헌을 참고한 설계 판단 |
| 24명 전체가 동일한 중요도로 등장 | 현재 담당자는 상단, 미배정 후보는 기본 목록, 다른 학생은 전체 필터 | 작업 관련성과 맥락 분리 원칙을 적용한 가설 |
| 제목만 굵고 큰 '평평한' 위계 | 상세 작업 영역을 넓고 밝게, 완료 역할을 작고 조용하게 | Still의 위치·구별성 결과를 참고한 해석 |
| 글을 지우다 조작 의미까지 사라질 위험 | 담당 학생·학생 추가의 짧은 라벨과 추가/제거 조작 유지 | Hornof의 라벨 있는 조직 결과를 참고한 해석 |
| 일괄적으로 카드와 테두리만 제거 | 배정 중·완료, 담당자·후보라는 의미 그룹을 먼저 설계 | Brumby & Zhuang의 조건부 그룹화 효과 |

## 실제로 검증해야 할 가설

논문을 읽고 그림을 바꾼 것만으로 '최적화 완료'를 주장하지 않는다. 후속 구현에서 이전 화면과 비교해 다음을 확인해야 한다.

1. 특정 역할에 미배정 학생을 추가하는 시간·잘못 선택한 횟수.
2. 전체 학생 필터를 찾아 이미 배정된 학생을 이동시키는 성공률.
3. 담당자 제거와 취소 후 값 유지.
4. 정원 초과·저장 실패·빈 후보 상태에서의 복구.
5. 반복 사용에서 역할의 위치 변화가 탐색을 방해하는지.

실제 교사 사용성 시험·아이트래킹·A/B 테스트는 이번 작업에서 수행하지 않았다.
