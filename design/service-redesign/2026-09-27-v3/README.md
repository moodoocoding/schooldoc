# PC 학생 역할 배정 — 3차 시안

홈과 모바일은 유지했다. 이번에는 PC 역할 배정의 정보 구조와 주 작업 영역만 다시 설계했다.

![PC 학생 역할 배정](01-role-assignment.png)

## 바뀐 점

- 상단 진행률, 전체 배정 인원, 미배정 인원, 하단 안내 문장을 삭제했다.
- 역할별 정원은 배정 중 역할 행의 1/2에만 둔다. 완료 역할은 하나의 그룹으로 낮은 위계에 배치한다.
- 상세 영역은 선택 역할 → 현재 담당자 → 추가할 학생 순서로 구성한다.
- 기본 목록은 미배정 학생만 보여주고, 전체 학생은 필터를 통해 접근하는 설계다. 같은 '미배정'을 네 행에 반복하지 않는다.
- 학생 추가·제거 행동을 해당 학생 가까이에 둔다. 통계가 화면의 주인공이 되지 않도록 했다.
- 전역 도구 목록은 배정 작업에서 물리고 '1인 1역' 복귀 경로를 남겼다. 홈의 전역 탐색 디자인 자체를 수정한 것은 아니다.
