# 2차 시안 제작 후 모의 검토

검토일: 2026-09-27. 저장소의 [웹디자이너](../../../pro/web-designer.md), [UX 디자이너](../../../pro/ux-designer.md), [UI 디자이너](../../../pro/ui-designer.md) 기준을 적용했다. 실제 전문가·교사의 인터뷰, 승인, 사용성 시험은 아니다.

## 마무리 수정

- 홈: 오른쪽 아래에 남던 빈 공간을 줄이기 위해 바로가기 여섯 개와 최근 완료 두 행을 본문 전체 폭으로 확장했다.
- 홈: 응답 진행 막대는 중립색으로 낮추고, 업무 상태 글자·점에 의미를 남겼다.
- 역할 배정·모바일: 작은 주홍색 글씨와 보조 회색 글씨가 충분히 진하도록 별도의 편집을 요청했다.
- 모든 편집에서 24명·20명 배정·4명 미배정, 학생별 역할, 모바일 '참가하지 않습니다' 응답을 유지하도록 지정했다.

## 수량과 상태 검토

역할 정원은 12×2=24자리, 현재 배정은 8×2+4×1=20명이다. 학생 21–24번 네 명은 미배정이다. 도서 정리에 17번 송도윤 학생 한 명이 선택돼 있어 1자리 남음과 일치한다. 배정 확인은 미완료 상태로 표시한다.

홈의 네 업무 응답은 20/24·22/24·24/24·16/24명이다. 미응답 4명, 미제출 2명, 응답 완료 표기와 일치한다. '진행 중'에는 아직 종료하지 않은 응답 완료 업무가 포함된 가상 예시다.

모바일 첫 장면은 한 쪽 문서가 모두 표시된 상태다. 두 번째 장면의 부정 응답과 보호자 이름이 세 번째 확인에 동일하게 표시된다. 실제 여러 쪽 문서의 로딩 실패·재시도는 이 정적 시안에 표현하지 않았다.

## 구현용 색상 목표와 한계

배경 #FBFAF8 기준 목표 본문 #252824, 보조 글씨 #686D66, 작은 강조 글씨 #B9472F를 사용한다. 주홍색 #D85C3D는 로고·체크·장식 요소로 한정한다. 초안에 지정했던 보조 #72756F와 주홍 글씨 #D85C3D는 작은 글씨에 더 진한 값이 필요해 조정했다.

색상값 계산과 이미지 편집 요청을 실제 생성 PNG의 모든 픽셀 측정이나 브라우저 접근성 검사로 간주하지 않는다. 정식 구현 때 CSS 토큰과 실제 렌더링에서 다시 검사해야 한다.

## 검증 범위

최종 PNG 전체 확인, 파일 디코딩·크기·문서 링크 검사, 역할·학생·응답 수량 비교를 수행했다. 앱 코드 변경이 없어 npm 타입 검사·단위 테스트·E2E·빌드·원격 검증은 실행하지 않았다. 이전 사용자 변경과 기존 시안을 보존했다.

명도 조정 후 역할 배정의 24명·12역할과 선택 상태를 다시 확인했다. 모바일 첫 장면은 참가 여부가 선택되고 보호자 이름은 아직 비어 있는 작성 중 상태이며, 두 번째·세 번째 장면은 보호자 이름까지 작성된 상태다. 세 장면의 부정 응답 의미는 일치한다.
