# SchoolDoc 시안 2차 — 제작 전 판단

기존 결과에 대한 사용자 피드백: 촌스럽고 상용 서비스 수준으로 느껴지지 않는다. 기존 125개 사이트 조사를 재사용하되 시각 방향을 새로 구성한다.

- 웹디자인 — **수정 필요**: 반복된 카드·테두리·짙은 제목·파란 강조가 과하다. 영역 구획을 글자·정렬·여백으로 옮기고 역할 배정의 24개 타일을 두 열의 명단으로 바꾼다.
- UX — **수정 필요 / 실제 사용성 판단 보류**: 역할 선택과 학생 선택은 유지하고, 미배정에 집중할 필터를 둔다. 장식을 줄이면서 상태 단서까지 지우지 않는다. 목록의 클릭 범위는 행 전체로 구현할 것을 전제로 한다.
- UI — **수정 필요 / 접근성 판단 보류**: 본문 글자를 읽기 쉽게 유지하고, 선택은 체크·강조·텍스트로 중복 표현한다. 완성 여부는 숫자와 상태명으로 구분한다. 구현되지 않은 정적 시안에서 키보드·보조기술 검사를 통과했다고 하지 않는다.

이 기록은 pro/web-designer.md, pro/ux-designer.md, pro/ui-designer.md를 읽고 적용한 AI 모의 검토이며 실제 전문가·교사 검토가 아니다.

## 시각 방향

따뜻한 흰색·차콜·소량의 주홍색, 굵기를 절제한 한글, 카드 없이 연결되는 명단. 24명 중20명 배정·4명 미배정, 12역할 중8개정원완료·4개1자리남음의 가상 데이터를 쓴다. 기존 사용자 코드 변경과 이전 시안은 보존한다.
