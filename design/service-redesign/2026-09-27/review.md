# 세 프로파일의 모의 디자인 검토

검토일: 2026-09-27. AI가 저장소의 프로파일을 적용한 **모의 검토**다. 실제 웹디자이너·UX/UI 전문가·교사 인터뷰나 승인을 받았다는 뜻이 아니다. 이번 작업은 이미지 시안이며 작동하는 화면 구현은 포함하지 않는다.

## 제작 전

| 관점 | 판단 | 근거 | 남은 위험과 제작 지침 |
| --- | --- | --- | --- |
| 웹디자인 | 수정 필요 | 배포된 역할 배정의 전체 화면에서 넓은 외곽 여백에 비해 작업 영역이 좁고, 반복된 상자가 핵심 상태를 약하게 만든다. 홈 소스는 도구 소개 중심이다. | 카드 장식만 변경하면 같은 문제가 남는다. 전체 구도와 열 높이, 이름의 크기부터 다시 설계한다. |
| UX | 수정 필요 / 효과 판단 보류 | 역할·학생·배정 상태를 연결해서 읽어야 한다. 홈은 도구 선택에 앞서 교사가 오늘 마무리할 일을 직접 보여줄 여지가 있다. | 실제 과제 시간·오류율은 측정하지 않았다. 미배정 필터와 명단을 가까이 두고 다음 행동을 명시한다. |
| UI | 수정 필요 / 접근성 판단 보류 | 완료·선택·미배정의 구분을 더 분명하게 할 필요가 있다. 아이콘 중심 전역 탐색은 도구 의미를 기억해야 한다. | 실제 명도 대비·포커스·터치 크기는 측정하지 않았다. 텍스트 라벨과 선택 체크를 병행한다. |

## 제작 후

전체 데스크톱 시안 두 장과 모바일 세 장면 보드를 확인했다. 작은 부분 캡처만으로 검토하지 않았다. 역할 배정은 한 학급 규모의 가상 명단 24명으로 확인했다.

| 관점 | 판단 | 시안에서 확인한 근거 | 남은 위험 |
| --- | --- | --- | --- |
| 웹디자인 | 이미지 구도 통과 / 실제 반응형 판단 보류 | 홈의 업무 표와 보조 요약이 구분된다. 역할 목록 12행과 학생 4열×6행의 높이가 비슷하고, 한 열 아래에 큰 무기능 공백이 남지 않는다. 본문 제목·이름·상태의 크기와 색 위계가 읽힌다. | 0명·최대 인원·긴 이름·1366px·200% 확대·390px 실제 렌더링은 미검증. 현재 이미지는 렌더링 가능한 컴포넌트가 아니다. |
| UX | 흐름 가설 통과 / 사용성 판단 보류 | 역할 선택과 학생 선택이 나란히 보이고 미배정 4명이 명시된다. 모바일은 원본 → 확대 입력 → 최종 확인을 제시한다. '참가하지 않습니다'가 선택 화면과 제출 전 확인에서 일치한다. | 클릭 과제·다른 역할 이동 확인·되돌리기·새로고침·저장 실패·값 보존은 작동 검증하지 않았다. 이미지에서 이런 기능이 구현됐다고 주장하지 않는다. |
| UI | 정적 상태 구분 통과 / 접근성 판단 보류 | 완료 역할은 체크와 2/2, 빈 역할은 1자리 남음, 선택 학생은 체크와 파란 테두리, 미배정 학생은 텍스트와 황색으로 구분된다. 미완료 상태의 배정 확인 버튼은 비활성이다. | 실제 DOM 접근 가능한 이름·44px 터치 영역·대비·키보드·Esc·스크린리더는 구현 후 검사 필요. 일부 회색 보조 글씨는 실기기에서 더 진하게 조정할 수 있다. |

## 검토 중 수정한 부분

역할 배정 최초 생성본에 '오늘의 할 일', '주간 계획', '학생 관리' 등의 임의 메뉴가 들어갔다. 이미지 편집으로 홈과 같은 실제 도구 목록으로 수정했다. 최종 전체 이미지에서 실제 도구 메뉴, 본문의 24명·12역할·20명 배정·4명 미배정, 17번 선택 상태가 유지됨을 다시 확인했다.

## 수량과 의미

- 역할 정원 합계: 12역할 × 2명 = 24자리.
- 배정 합계: 8역할 × 2명 + 4역할 × 1명 = 20명.
- 미배정: 학생 21–24번, 총 4명.
- 도서 정리: 정원 2명, 현재 17번 학생 1명. '1명을 더 선택하세요'와 일치.
- 홈 가정통신문: 20/24명 → 4명 미응답.
- 홈 자료 수합: 22/24명 → 2명 미제출.
- 홈 완료 응답: 24/24명.
- 모바일: 원본 1/1쪽을 전부 표시한 짧은 가상 문서. 실제 여러 쪽 PDF에서는 모든 페이지 표시 성공 확인·실패 복구가 추가로 필요하다.
- 모바일 최종 확인은 부정 응답을 동의로 바꾸지 않는다.

## 검증 범위와 기록

실행: 125개 고유 사이트·출처·검색어 개수 검사, 생성 이미지 전체 시각 확인, 산출물 파일·문서 링크·PNG 검사. 앱 코드를 변경하지 않았으므로 npm 타입 검사·단위 테스트·E2E·빌드는 실행하지 않는다. 배포나 원격 Supabase 검증도 이 작업의 범위가 아니다.

검사 결과: 고유 도메인 125개, 조사 표 125행, 각 사이트 검색어와 동일 공식 도메인 출처 존재, 로컬 문서 링크 11개 정상. PNG 디코딩 정상: 홈 1499×1049, 역할 배정 1500×1049, 모바일 보드 1568×1003. 생성 목표 크기와 실제 출력 크기는 다르므로 실제 PNG 크기를 기록했다.
