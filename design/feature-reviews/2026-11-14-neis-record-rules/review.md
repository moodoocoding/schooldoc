# Neis Helper 기재요령 반영 검토

AI의 모의 검토와 실제 AI 생성 비교 기록이다. 실제 전문가·교사 인터뷰나 승인 결과가 아니다.

## 요청과 범위

- 2026 학교생활기록부 기재요령(초등)과 「교과세특 기재 예시 도움 자료」에서 적용할 부분을 반영한다.
- 교사는 평가계획·수행평가지·상중하 성적만으로 작성한 평어를 최종 수정해 사용한다. 관찰 메모 입력, 초안·AI 표기, 학생별 확인 단계는 추가하지 않는다. 학생 간 문장 순서 변경은 유지한다.
- 항목명은 `성취수준 및 특기사항`으로 바꾼다.

## 화면 변경과 세 관점 판단

화면 구조는 그대로이고 문구·표시만 추가했다.

| 관점 | 판단 | 근거 | 남은 위험 |
| --- | --- | --- | --- |
| 웹디자인 | 통과 | 평가 목록의 `기준 보기` 안에 `수업·평가 과정과 채점 요소`를 성취기준·상중하 기준 아래 한 줄로 추가했다. 결과 행의 경고는 기존 반복 경고와 같은 위치·색으로 `기재요령 확인`을 표시한다. | 긴 채점 요소 요약이 접힌 영역 안에서 길어질 수 있다 |
| UX | 통과(모의) | 분량 선택 아래 권장 분량 안내는 평가당 150자를 넘을 때만 나타나고 선택을 막지 않는다. 기존 `평가계획 분석`·`평어 만들기` 두 번의 흐름은 유지된다. | 교사가 채점 요소를 고칠 때 `원본과 대조하거나 수정`을 열어야 한다 |
| UI | 통과 | 새 입력칸은 보이는 라벨과 같은 접근 가능한 이름을 가진다. 경고는 색과 문자로 함께 구분한다. | 화면낭독기 실기기 확인은 하지 않았다 |

## 실제 AI 생성 비교(시험 함수 `neis-helper-next`, 로컬 화면)

- 자료: 사용자가 제공한 4학년 2학기 평가계획 PDF와 국어 성적표 PDF(24명). 저장소에는 넣지 않았다.
- 평가계획 분석: 성취기준 코드 2개 보존, 평가 시기(10·11·12월), 기준안의 평가 항목(사실 근거, 출처·소감, 친구 의견 존중, 편지 짜임 요소)이 `taskDetails`로 추출됐다. 처음에는 평가요소 대신 단원명이 들어가 지침을 고쳤다.
- 성적표 PDF의 `듣기·말하기` 가운뎃점이 U+007F로 읽혀 연결이 빠지는 문제를 발견해 보이지 않는 문자를 무시하도록 고쳤다.
- 평가 3개·300자: 24명 완성, 중·하에 상 수준 수식어 없음, 평가어(돋보임·뛰어남 등) 학생당 최대 2회.
- 평가 2개·300자: 수정 전 24명 모두 분량 미달로 실패, 수정 후 24명 270~319자 완성.
- 국어 문체 예시 유무 비교(각 1회): 수준 표현·문장 품질 차이가 작고 예시 문구 복사 0회. 예시 있음 24명 완성, 없음 21명 완성(분량 2, 중복 1). 1회씩이라 우연일 수 있다. 다른 교과 예시·어휘 목록은 만들지 않기로 했다.

## 남은 위험

- 편지 짜임 요소처럼 채점 요소가 구체적이면 같은 목록이 여러 학생에게 반복된다. 교사가 옮길 때 다듬어야 한다.
- 평가계획 분석은 약 80초 걸렸고 한 번 연결 오류가 있었다.
- 다른 교과·다른 학교 양식의 실제 평가계획으로는 확인하지 않았다.
