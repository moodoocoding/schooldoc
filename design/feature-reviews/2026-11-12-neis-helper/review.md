# Neis Helper 화면 검토 (codex)

AI의 모의 검토이며 실제 전문가·교사 인터뷰나 승인 결과가 아니다.
범위: 기존 메뉴 이름 변경, 네 기능의 개발 예정 버튼과 안내 화면. 실제 기록 기능은 포함하지 않는다.

## 구현 전 세 프로파일 검토

| 관점 | 판정 | 근거·반영 방향 | 남은 위험 |
| --- | --- | --- | --- |
| 웹디자인 | 수정 필요 | 기존 카드 한 장은 네 영역을 구분하기 어렵다. 안내 화면에 같은 비중의 2×2 버튼을 배치한다. | 좁은 화면의 긴 한글 이름 줄바꿈 |
| UX | 수정 필요 | 개발 중인 홈 카드가 비활성이어서 예정 기능을 볼 수 없다. 안내 진입만 열고 네 기능은 비활성 상태를 명시한다. | 실제 입력 기능으로 오인할 가능성 |
| UI | 수정 필요 | 홈·검색·퀵 메뉴 이름과 동작을 일치시킨다. 버튼의 접근 가능한 이름에 개발 예정 상태를 포함한다. | 퀵 메뉴의 기존 마우스 전용 동작 |

학생 명단·완료 상태·입력 저장은 이번 안내 화면에 존재하지 않아 명단 규모별 점검 대상이 아니다.
예정 기능 네 개 전체와 가장 긴 제목을 대표 콘텐츠로 확인한다.

## 구현 후 검토

### 1차 구현의 여섯 독립 관점 모의 평가

각 행은 서로 다른 기준으로 수행한 AI 모의 평가다. 여섯 명의 실제 전문가 검토나 별도 에이전트 검토를 의미하지 않는다.

| 관점 | 판정 | 전체 화면·행동 근거 | 수정 요구 또는 한계 |
| --- | --- | --- | --- |
| 웹디자인: 정보 위계 | 통과 | 제목 아래 네 영역을 같은 크기로 배치하고 각 버튼에 개발 예정을 표시했다. | 실제 입력 화면은 미구현 |
| 웹디자인: 화면 밀도 | 수정 필요 | 390px 화면에서 최소 높이 172px 카드 네 개가 불필요한 세로 공간을 차지했다. | 모바일 최소 높이를 148px로 줄이고 데스크톱은 172px 유지 |
| UX: 학생 사용 흐름 | 판단 보류 | 이 화면은 관리자용 안내이며 학생 입력·공개 참여 흐름이 없다. 관리자 진입·돌아가기는 키보드로 확인했다. | 학생용 사용성 시험으로 보고하지 않음 |
| UX: 교실 전자칠판 흐름 | 판단 보류 | 200% 확대에서 안내·기능명을 읽을 수 있으나 교실용 기능은 없다. | 실제 전자칠판이나 수업 사용성은 미검증 |
| UI: 접근성 | 통과 | 주 영역 Axe 위반 0건. 홈·퀵 메뉴 진입과 돌아가기의 Enter 조작, 네 버튼의 disabled 상태를 검사했다. | 자동 검사와 모의 인증의 범위 |
| UI: 반응형·상태 표현 | 수정 필요 | 가로 넘침은 없지만 확대 화면에서 한글 설명의 어절이 나뉘었다. 개발 중·개발 예정 상태는 문자로 구별된다. | 제목·설명·하단 안내에 어절 단위 줄바꿈 적용 |

### 2차 개발과 재검증

- 모바일 카드 최소 높이를 148px로 조정하고 큰 화면의 172px는 유지했다. 제목·설명·하단 안내에 `break-keep`을 적용했다.
- 1366px·390px·683px/200%의 전체 페이지 캡처를 다시 확인했다. 데스크톱 두 열의 높이가 같고, 모바일 네 버튼이 순서대로 표시되며 확대 화면의 설명은 어절 단위로 줄바꿈된다. 잘림·겹침·가로 넘침은 확인되지 않았다.
- 최종 캡처: `test-results/neis-final/admin-tool-visibility-Neis-Helper-네-기능-안내와-돌아가기-{desktop,mobile,zoom}/neis-helper-full.png`.
- 세 프로파일의 최종 판단: 웹디자인 통과(열 균형·모바일 밀도), UX 통과(이번 안내 진입·복귀 범위), UI 통과(키보드·상태·반응형). 실제 기록 입력, 명단 규모별 배치, 완료·오류·저장 상태는 구현 후 별도 검증이 필요하다.

## 검사 결과와 한계

- `npm run typecheck`: 통과.
- `npm run lint`: 통과. 기존 경고 4건은 남아 있다.
- `npm test`: 70개 파일, 555개 테스트 통과.
- `CI=1 npm run test:e2e -- tests/e2e/admin-tool-visibility.spec.ts tests/e2e/app-shell-scroll.spec.ts`: 최초 37건 중 36건 통과. 새 셸 테스트의 가상 인증 객체에 메타데이터가 빠져 1건 실패했다. 테스트 객체를 보완한 뒤 해당 Neis Helper 셸 테스트 1건 재실행 통과.
- 2차 화면 수정 후 `CI=1 npm run test:e2e -- tests/e2e/admin-tool-visibility.spec.ts --grep 'Neis Helper 네 기능'`: 3건 통과. 각 화면의 주 영역 Axe 위반 0건, 원격 호출·브라우저 오류 없음.
- `git diff --check`: 통과.
- E2E는 로컬 데모 서버와 모의 인증이다. 원격 Supabase·운영 로그인·운영 배포 검증이 아니다. 서버·DB 변경은 없으며, push·병합·배포는 수행하지 않았다.
- 외부 개발 이력 `../schooldoc-docs/development-history.md`는 이 checkout에서 확인되지 않아 작성하지 않았다.
