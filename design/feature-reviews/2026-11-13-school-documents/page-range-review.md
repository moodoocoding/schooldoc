# 학교 문서 작성 화면 검토 (codex)

AI의 모의 검토다. 실제 전문가 6명·교사 인터뷰·승인·사용성 시험을 뜻하지 않는다.
범위: 운영계획서 첫 단계의 희망 출력 쪽수(1~5쪽), 유형별 작성 기준 안내, 분량에 맞춘 생성 구조.

## 구현 전 세 프로파일 검토

| 관점 | 판단·근거 | 남은 위험 |
| --- | --- | --- |
| 웹디자인 | 사용자가 생성 전에 분량과 유형을 바로 고를 수 있게 두 선택을 첫 단계에 유지한다. 쪽수 선택은 구성 목표와 실제 지면 확인 위치를 안내해야 한다. | 긴 안내가 좁은 화면에서 선택을 밀어낼 수 있음 |
| UX | 공문 처리보다 앞에서 원하는 분량과 계획 유형을 설정하는 흐름은 AI가 결과를 만들기 전에 기준을 정한다. 출력 쪽 수는 한글 조판 결과와 다를 수 있음을 밝혀야 한다. | 선택 수와 실제 HWPX 쪽 수의 차이 |
| UI | 필드마다 접근 가능한 이름을 연결하고 네이티브 선택 UI·키보드 포커스·터치 크기를 유지한다. 유형 안내는 접고 펼칠 수 있어야 한다. | 작은 화면에서 긴 한글 설명의 줄바꿈과 스크롤 |

## 1차 구현의 여섯 독립 관점 모의 평가

판정은 첫 구현의 코드와 데스크톱 전체 화면, 390px 모바일 폭 렌더링을 각각 살펴본 결과다.

| 관점 | 판정 | 화면·동작 근거 | 수정 요구 또는 한계 |
| --- | --- | --- | --- |
| 웹디자인: 정보 위계 | 통과 | 첫 단계에 쪽수와 유형이 같은 순서로 제시되고, 선택 직후 분량별 구성 목표가 표시된다. | 페이지 실제 수 안내가 상단과 필드 아래에서 반복됨 |
| 웹디자인: 화면 밀도 | 2차 반영 필요 | 데스크톱은 넓은 필드와 짧은 도움말로 읽힌다. 390px에서는 필드가 세로로 쌓이고 안내가 자연스럽게 줄 바뀐다. | 중복되는 쪽수 변동 안내를 한 곳으로 줄인다. |
| UX: 학생 사용 흐름 | 해당 없음 | 학생 입력·공개 참여가 없는 교사용 계획서 작성 설정 화면이다. | 학생 사용성으로 평가하거나 보고하지 않는다. |
| UX: 교실 전자칠판 흐름 | 해당 없음 | 전자칠판 사용을 위한 화면이 아니다. 단계 표시와 교사용 설정 흐름만 확인했다. | 실제 교실·전자칠판 사용은 미검증 |
| UI: 접근성 | 부분 통과 | 필드 이름, 네이티브 선택, 44px 이상 선택 영역과 접기 항목이 코드에 있다. 브라우저 접근성 트리에서 두 선택의 이름과 1~5쪽 옵션을 확인했다. | 별도 키보드 전 구간·스크린리더 검증과 자동 접근성 검사는 수행하지 않음 |
| UI: 반응형·상태 표현 | 통과 | 1232px 브라우저 화면과 390px 폭에서 가로 넘침 없이 표시된다. 1~5쪽 목표 문구가 선택값에 따라 바뀌며 유형 안내는 접힘/펼침 상태를 갖는다. | 긴 유형별 설명 전체의 모바일 읽기는 스크롤이 필요함 |

## 2차 개발과 재검증

- 상단 설명에서 글꼴·조판에 따른 쪽수 변동 문장을 덜어 중복을 줄였다. 분량별 필드 아래에는 목표 구성과 저장 전 지면 미리보기 확인을 안내한다.
- 2차 후 모바일 390px 화면을 다시 확인했다. 상단 설명은 한 줄 덜 차지하고, 5쪽 선택 도움말과 유형 선택 안내가 줄 바뀜 상태로 읽힌다. 가로 넘침은 보이지 않았다.
- 유형 목록에서 자동 외 8개 항목을 확인했고, 교원 연수 선택 후 해당 작성 지침과 권장 목차가 펼쳐지는 화면을 확인했다. 다른 유형별 지침은 공유 참조 데이터의 목차·작성·검토 정의와 화면 연결을 코드로 확인했다.
- 데스크톱 화면은 첫 구현에서 확인했고, 2차 수정은 도움말 문구 한 줄을 줄이는 변경이다. 실제 AI 생성, 원격 Supabase, 운영 로그인, 결과 HWPX의 한글 조판은 이번 화면 검토에 사용하지 않았다.
- 세 프로파일의 최종 판단: 웹디자인 통과(위계와 중복 제거), UX 통과(교사용 첫 단계 흐름; 학생/전자칠판은 해당 없음), UI 부분 통과(선택 이름·반응형 확인; 키보드·스크린리더 전 구간 미검증).

## 검사 결과와 한계

- `npm run typecheck`: 통과.
- `npm exec --yes --package=deno@2.9.6 -- deno check --no-config --no-lock supabase/functions/school-plan/index.ts`: 통과. 최초 실행에서 발견한 쪽수 변수 범위 오류를 고친 뒤 재검사했다.
- `npm run lint`: 통과. 기존 다른 파일 경고 4건이 남아 있다.
- `git diff --check`: 통과.
- 단위·E2E 테스트는 실행하지 않았다. 별도의 테스트를 요청받지 않았으며 자동 테스트를 추가하지 않았다.
- 실제 쪽 수는 글꼴과 조판에 따라 선택 목표보다 많거나 적을 수 있다. 초안 작성 시 분량별 항목 한도와 배치를 적용하고 저장 화면에서 초과 여부를 알리지만, 초과 내용을 자동으로 줄이거나 저장을 막지 않는다.
- 화면 검토는 로컬 임시 렌더와 모의 인증만 사용했다. 실제 교사 검토, 운영 인증, 외부 AI 요청, 배포 검증이 아니다.
