## 실제 운영 검사

실제 학생·학부모 정보는 사용하지 않았다. 가상가·가상나·가상다·가상라 4명을 3, 1, 4, 2 순서로 붙여넣어 번호순 변환을 확인했다. 기존 로그인 세션과 운영 API를 사용했다.

1. 새 행동특성 메뉴 및 직접 URL이 정상 열렸다.
2. 4명에게 특성과 교사 메모를 넣고 학급 작성 버튼을 한 번 눌렀다. 실제 모델 응답 4개가 각 학생 행에 들어가고 완료 4명·미완료 0명으로 전환됐다. API를 모의 응답으로 대체하지 않았다.
3. 완전히 같은 특성·메모를 넣은 1·3번은 각각 '모둠', '준비물을'로 시작하고 전개 순서와 표현이 달랐다. 다른 학생 시작은 '스스로', '의견이'였고 첫 단어·첫 세 글자·동일 문장 중복 경고는 0명이다. 이는 이 4명 표본의 결과이며 모든 학급의 문장 다양성을 보장하는 증거는 아니다.
4. 개선 기록이 없다고 명시한 학생에게 이미 좋아졌다는 사실을 만들지 않고 감정 표현의 연습 필요성과 발전 가능성을 썼다.
5. 짧은 메모를 사용해 400자 옵션에서도 최초 결과는 88~111자였다. 없는 사실로 분량을 채우지 않는 우선순위가 작동한 결과다. 풍부한 입력의 400자 분량 품질은 별도 실제 표본을 추가하지 않았다.
6. 2번 문장을 직접 수정한 뒤 Excel을 저장했다. 브라우저 자동화의 다운로드 대기 연결은 끊겼으나 내려받은 파일을 별도로 읽어 헤더와 데이터 4행, 1~4번 순서, 직접 수정한 문장, 모든 행의 글자 수·UTF-8 바이트 일치를 확인했다.
7. 생성 완료 시점 브라우저 로그에서 확인한 경고는 MetaMask 확장 프로그램 URL의 메시지였다. 앱 오류는 관찰되지 않았다. 장시간 전체 로그를 수집하거나 모든 외부 확장 오류를 해결한 것은 아니다.

8. 운영 함수에 인증 헤더 없는 빈 JSON POST를 보내 HTTP 401 거부를 확인했다. AI 호출에 사용할 학생 자료나 계정 비밀값은 보내지 않았다.
