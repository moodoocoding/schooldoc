# 프로필 담당학급 항목 모의 화면 검토

대상: 설정 > 프로필 & 소속 학교. 웹·UX·UI 디자이너 프로파일을 적용한 AI 모의 검토이며, 실제 전문가나 교사의 검토는 아니다.

| 관점 | 수정 전 판단과 근거 | 수정 후 판단과 근거 | 남은 위험 |
| --- | --- | --- | --- |
| 웹디자인 | `담당 학년 / 학급 / 직책`은 한 항목 이름으로 길어 다른 두 필드보다 시선이 분산됐다. | `담당학급`이 데스크톱과 390px 모바일 전체 화면에서 한 줄로 표시되고, 기존 필드 간격과 열 균형을 유지했다. | 로그인된 프로필의 긴 실제 입력값은 확인하지 않았다. |
| UX | 필드 이름이 입력 목적보다 넓어 보였다. 예시 `3학년 2반 담임`은 의도를 설명한다. | 짧은 이름과 기존 예시가 함께 입력 목적을 전달한다. 저장 키 `gradeClass`는 유지해 기존 값을 그대로 읽는다. | 로그인되지 않은 개발용 화면에서는 저장 동작을 시험할 수 없다. |
| UI | 기존 `<label>`이 입력칸과 연결되지 않아 접근 가능한 이름이 없었다. | `htmlFor`/`id`를 연결했고 브라우저 접근성 트리에서 입력칸 이름이 `담당학급`으로 확인됐다. 모바일 화면의 문서 너비는 390px로 가로 넘침이 없었다. | 브라우저 200% 확대 상태는 확인하지 못했다. |

전체 화면은 로컬 개발 서버의 데스크톱 기본 크기와 390px 모바일에서 확인했다. 이 변경은 프로필 단일 항목이므로 가상 학생 명단의 빈 공간·완료 상태 비교는 해당하지 않는다.
