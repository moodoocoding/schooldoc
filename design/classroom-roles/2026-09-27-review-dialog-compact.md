# 학생 배정 작업·확인창 간소화 모의 검토

`pro/web-designer.md`, `pro/ux-designer.md`, `pro/ui-designer.md`를 기준으로 한 AI 모의 검토다. 실제 전문가나 교사의 평가가 아니다.

## 구현 전

| 관점 | 판단 | 근거 | 조치 |
| --- | --- | --- | --- |
| 웹디자인 | 수정 필요 | PC 배정 화면의 검색·필터가 학생 카드 위에 별도 행을 차지한다. 확인창은 넓은 화면에서도 역할을 한 열로 나열한다. | 보조 조작을 역할 제목 줄에 모으고, 확인창은 화면 폭에 따라 여러 열로 배치한다. |
| UX | 수정 필요 | 23명 정도의 학급에서도 검색창이 먼저 눈에 띄고, 확인창의 마지막 역할과 확정 버튼까지 긴 내부 스크롤이 필요하다. | 일반 명단은 학생 카드를 바로 보여주고, 많은 학생일 때만 검색을 열 수 있게 한다. 확인창의 주요 동작은 항상 볼 수 있게 한다. |
| UI | 수정 필요 | 확인창의 반복된 카드 테두리와 넓은 여백 때문에 배정 정보를 훑기 어렵다. | 역할명과 담당 학생을 간결한 목록으로 묶고, 키보드·포커스·긴 이름·좁은 화면을 확인한다. |

## 구현 후

| 관점 | 판단 | 근거 | 남은 위험 |
| --- | --- | --- | --- |
| 웹디자인 | 통과 | [PC 배정 전체 화면](verification/assignment-compact-desktop.png)에서 23명 명단이 역할 제목 바로 아래 시작한다. [PC 확인창](verification/review-dialog-desktop.png)은 12개 역할을 3열 4행으로 보여주며 화면 가운데에 놓인다. [모바일 확인창](verification/review-dialog-mobile.png)은 한 열로 읽힌다. | 아주 긴 역할·학생 이름의 실제 분포는 가상 데이터로만 확인했다. |
| UX | 통과 | 일반 학급 규모에서는 검색을 숨기고, 60명일 때만 제목 줄의 버튼으로 열 수 있다. 필터와 정원 변경은 제목 줄에 모았다. 확인창의 역할 목록만 내부 스크롤하며 60명·30역할에서도 돌아가기·확정하기가 보인다. | 실제 교사의 작업 속도와 선호도는 시험하지 않았다. |
| UI | 통과 | 확인창의 반복된 카드 테두리를 없애고 역할명·번호·이름을 얇은 구분선으로 나눈다. 390px·195px 폭, Esc 후 초점 복귀, 자동 접근성 검사와 키보드 조작을 확인했다. | 실제 교사 인터뷰·승인·사용성 시험은 없었다. |

캡처에는 가상 학생만 사용했다. `npm run typecheck`, `npm run build`, `npm test`(413개), 관련 Playwright 44개가 통과했다. `npm run lint`도 통과했으며 변경 범위 밖의 기존 경고 6개가 남아 있다.
