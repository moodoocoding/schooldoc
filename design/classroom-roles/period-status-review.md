# 1인 1역 운영 기간 통계 화면 검토 (codex)

현재 화면은 아래의 **홈 요약과 상세 분리**를 따른다. 홈에 표와 실천율이 있던 화면은 초기 시안의 검토 기록이다.

## 구현 전

| 관점 | 판정과 근거 | 확인할 위험 |
| --- | --- | --- |
| 웹디자인 | 수정 필요. 홈의 오늘 현황 아래에 운영 기간과 학생별 통계를 배치한다. 학급 전체를 처음부터 펼치면 주요 기능이 밀리므로 처음에는 5명을 표시한다. | 데스크톱·390px 모바일·좁은 화면에서 날짜와 열의 균형, 긴 이름, 명단을 펼친 전체 페이지를 확인한다. |
| UX | 수정 필요. 기존 지난 기록은 달력 월로 조회하므로 월을 넘는 배정은 한 번에 비교할 수 없다. 실제 배정 기간과 집계 마지막 날짜를 표시하고, 기록 횟수와 비율을 선택 기준으로 제공한다. | 종료 직후 조회, 동점, 미기록, 교사 정정, 배정이 없는 경우에 오해 없이 사용할 수 있는지 확인한다. |
| UI | 검증 예정. 기존 카드·버튼 스타일과 시맨틱 표를 사용한다. 정렬과 전체 보기의 접근 가능한 이름 및 키보드 포커스를 확인한다. | 좁은 화면과 200% 확대 상당의 너비에서 상태 구분, 줄바꿈, 가로 넘침을 확인한다. |

## 1차 화면의 여섯 가지 모의 검토와 2차 반영

가상 명단으로 수행한 AI 검토다. 실제 교사·학생 인터뷰, 전문가 승인, 운영 교실 시험은 수행하지 않았다.

| 관점 | 1차 판정·근거와 수정 요구 | 2차 확인·남은 위험 |
| --- | --- | --- |
| 웹디자인 · 정보 위계 | 수정 필요. 데스크톱에서 기간 범위와 집계 종료일이 같은 문장처럼 붙어 보였다. 두 날짜 정보 사이에 구분을 넣는다. | 통과. 데스크톱은 구분 기호를, 모바일은 줄바꿈을 사용해 두 날짜의 역할이 읽힌다. |
| 웹디자인 · 화면 밀도 | 수정 필요. 390px에서 새로고침이 날짜 아래 한 줄을 쓰고, 320px에서는 정렬과 전체 보기가 한 줄에 들어가지 않았다. 새로고침을 제목 옆으로 옮기고 펼침 버튼 문구를 줄인다. | 통과. 23명 미리보기와 60명 전체 보기에서 동일한 열을 유지한다. 60명 전체 보기는 문서 스크롤이 길어진다. |
| UX · 학생 사용 흐름 | 통과. 학생용 모바일 전체 화면은 개인 역할과 실천 상태를 표시하며 교사용 비교 표가 노출되지 않는다. 현재 구분을 유지한다. | 통과. 공개 타일과 학생 상세의 기존 Chrome 데모 테스트에서 재확인했다. |
| UX · 교실 전자칠판 흐름 | 통과. 전자칠판 전체 화면에서 기존 읽기 전용 타일을 확인했다. 비교 표는 교사용 홈에 둔다. | 통과. 공개 교실 표시 데모에서 실천 상태와 이름 가림을 확인했다. 실제 전자칠판 환경은 미검증이다. |
| UI · 접근성 | 통과. 표에 열·행 머리글을 연결했고 정렬 이름을 제공했다. 전체 보기 버튼을 표 앞에 두어 펼친 뒤에도 포커스를 유지한다. | 통과. Enter로 23명을 펼친 뒤 접기 버튼의 포커스와 axe 검사 결과를 확인했다. 실제 화면 낭독기로는 검증하지 않았다. |
| UI · 반응형 및 상태 표현 | 수정 필요. 320px에서 머리글 일부가 세 줄로 깨졌다. 머리글의 글자 단위 줄바꿈을 막고 모바일에서 표 너비를 넓힌다. | 통과. 320px에서도 상태 머리글이 한 줄로 표시된다. 긴 이름은 여러 줄로 보인다. 기록이 없는 경우는 0% 대신 대시와 접근 가능한 이름으로 표시한다. |

## 집계 기준과 화면 증거

- 현재 운영 기간의 시작일부터 오늘까지 집계한다. 진행 중인 기간이 없으면 `최근 종료 기간`을 표시한다. 역할별 실천 요일, 학급의 실천 요일과 제외일, 교사가 기록한 `해당 없음`을 반영한다. 현재 배정 변경으로 배정 기간이 나뉘면 저장된 각 기간의 날짜를 기준으로 삼는다.
- 실천율은 `했어요 / (했어요 + 못했어요)`를 정수 퍼센트로 표시한다. 미기록은 별도 열에 표시한다. 기본 정렬은 `했어요 많은 순`이고, 정렬 값이 같으면 번호순이다. 교사가 표를 보고 자체 점수를 낼 수 있다.
- Playwright 출력의 `teacher-period-desktop.png`, `teacher-period-mobile.png`, `teacher-period-expanded-320.png`, `teacher-period-expanded-683.png`, `teacher-period-60-mobile.png`, `teacher-home-mobile.png`를 확인했다. 683px는 1366px에서 200% 확대에 해당하는 레이아웃 너비를 재현한다.
- 긴 기간은 기존 교사용 기록 API에 허용 범위로 나눠 조회한다. 경계 날짜와 일부 요청 실패를 단위 검사했다. 실제 Supabase 연결과 운영 배포는 이번 작업의 검증 범위 밖이다.
- 공유 개발 일지는 이 워크트리에서 찾을 수 없어 이번 화면 검토와 결과를 여기에 기록했다.

## 검증 결과

- `npm run typecheck` 및 `npm run build` 통과. 빌드는 기존 번들 크기 및 동적 가져오기 경고를 표시했다.
- `npm run lint` 통과. 변경 범위 밖의 경고 4건이 있다.
- `npm test` 671건 통과.
- `npm run test:e2e -- tests/e2e/classroom-roles.spec.ts tests/e2e/classroom-roles-public-layout.spec.ts` Chrome 데모 39건 통과.

### 분리 후 1차·2차 모의 검토

가상 명단과 Chrome 데모를 사용한 AI 모의 검토다.

| 관점 | 1차 판단과 수정 요구 | 2차 근거와 남은 위험 |
| --- | --- | --- |
| 웹디자인 · 정보 위계 | 수정 필요. 모바일에서 상세 링크가 운영 날짜 아래로 밀렸다. 제목과 링크를 한 행에 배치하고 날짜를 다음 행에 둔다. | 통과. 390px와 320px 홈에서 링크 위치가 제목 오른쪽에 고정되고, 데스크톱의 제목·기간·링크는 한 행에 들어간다. |
| 웹디자인 · 화면 밀도 | 수정 필요. 1차 홈 카드의 제목 행이 오늘의 현황보다 두꺼웠다. 링크의 터치 영역을 유지하면서 카드 여백을 줄인다. | 통과. 1366px 전체 화면에서 두 카드 높이가 비슷하다. 모바일은 3개 합계를 한 행에 표시한다. 320px에서 19,020회는 단위가 다음 줄에 놓인다. |
| UX · 학생 사용 흐름 | 통과. 학생별 통계는 교사용 화면에 있다. 학생 화면의 역할 검색과 실천 흐름을 기존대로 사용한다. | 통과. 공개 모바일 전체 화면과 학생 상세 흐름을 데모에서 재확인했다. 실제 학생 사용 시험은 미실행이다. |
| UX · 교실 전자칠판 흐름 | 통과. 전자칠판은 가상 명단의 읽기 전용 상태를 표시한다. 상세 표 진입과 전자칠판 진입은 별도 경로다. | 통과. 교실 표시 전체 화면에서 가려진 이름과 완료·미완료·미기록을 확인했다. 실제 전자칠판 환경은 미검증이다. |
| UI · 접근성 | 통과. 같은 표시 문구를 쓰는 두 링크 중 이달 카드의 링크에 운영 기간을 구별할 수 있는 접근 가능한 이름을 제공했다. | 통과. Enter로 상세를 열면 페이지 제목에 초점이 이동한다. 제목과 표 머리글, 홈 복귀, 상세 axe 검사 결과를 확인했다. 화면 낭독기 실기 시험은 미실행이다. |
| UI · 반응형 및 상태 표현 | 수정 필요. 320px 상세에서 학생 이름 열이 좁고 집계 종료일이 새로고침과 떨어져 있었다. 모바일 표 너비를 넓히고 집계일을 운영 날짜 가까이 둔다. | 통과. 1366·683·390·320px 전체 화면에서 머리글을 읽을 수 있고 가로 넘침이 없다. 최대 60명과 긴 이름을 표시했다. 320px에서 일부 이름은 여러 줄에 놓인다. |

- 홈은 배정된 실천일의 `했어요·못했어요·미기록` 합계를 횟수로 표시한다. 상세는 같은 운영 기간의 학생별 성공·못했어요·미기록 횟수를 표시한다. 성공 횟수순과 학생 번호순으로 정렬할 수 있다.
- 23명 학급의 운영 설정과 홈·상세에 표시되는 2026-11-11~2026-11-30 날짜, 이전 기간과 미래 날짜의 제외, 종료 기간 조회, 상세 새로고침 뒤 홈 합계, 1년 기간의 60명 미기록 합계를 자동 검사한다.
- `test-results/role-period-final`의 홈·상세 전체 화면과 학생용 모바일·전자칠판 전체 화면을 확인했다. 운영 Supabase와 배포는 이번 검증 범위에 포함하지 않았다.
- 최종 분리 화면에서 타입 검사·린트·빌드, 단위 테스트 671건, 1인 1역 Chrome 데모 39건, 1인 1역 앱 스크롤 검사 10건을 통과했다. 린트·빌드 경고는 변경 범위 밖에서 발생했다.
