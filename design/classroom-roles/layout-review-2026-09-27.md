# 학생 역할 배정 좌우 레이아웃 검토 (codex)

검토일: 2026-09-27. 실제 전문가·교사 인터뷰가 아니라 `pro/`의 세 검토 프로파일을 적용한 AI 내부 검토다. 학생 이름은 가상 데이터만 사용했다.

## 문제와 변경

- 조건: 데스크톱 1366×900, 가상 학생 23명, 기본 역할 18개. 기존 한 줄 역할 목록은 학생 선택 패널보다 **440px** 길었다. 학생 명단 아래 오른쪽에 무기능 공간이 남았다.
- 역할 목록을 데스크톱 2열로 압축하고 왼쪽 폭을 340px로 조정했다. 두 패널을 억지로 같은 높이로 늘리지 않았다.
- 역할 탐색 영역은 옅은 파란색(`#EAF3FB`), 학생 선택 영역은 흰색으로 구분했다. 선택한 역할은 테두리·글자 굵기·`aria-pressed`로도 표시한다.
- 모바일에서는 기존 단일 열 역할 선택 대화상자와 학생 선택 흐름을 유지했다.

## 세 관점의 구현 전후 검토

| 관점 | 구현 전 판단 | 구현 후 판단과 근거 | 남은 위험 |
| --- | --- | --- | --- |
| 웹디자이너 | 수정 필요: 좌우 높이 차이 440px, 오른쪽 하단 공백이 큼 | 통과: 같은 23명·18역할 조건에서 높이 차이 80px 이하를 E2E로 확인. 전체 화면 캡처에서 하단 조작 영역이 목록과 가까움 | 역할명이 매우 길면 왼쪽 버튼 높이가 늘 수 있음 |
| UX 디자이너 | 수정 필요: 18역할을 한 줄씩 훑어야 해 학생 명단과 왕복이 길어짐 | 통과: 데스크톱은 2열에서 역할을 고르고 오른쪽 학생을 연속 선택. 모바일 역할 선택 방식과 기존 배정·취소 흐름 유지 | 실제 교사의 역할 탐색 시간은 측정하지 않음 |
| UI 디자이너 | 수정 필요: 양쪽 모두 흰색이라 조작 영역 구분이 약함 | 통과: 좌우 배경색이 다르고, 활성 역할에는 테두리·굵기·상태 속성이 있음. 데스크톱 axe 검사와 1024px 가로 넘침 검사 통과 | 실제 사용 환경의 모니터 색감·고대비 설정은 별도 확인 필요 |

자동 검사와 AI 검토는 실제 사용성 평가를 대신하지 않는다. **실제 5·6학년 담임에게 검토를 받은 적은 없다.** 이전 가상 담임 6명의 의견은 모의 설계 검토였으며 실제 참여자의 승인으로 보고하지 않는다. 실사용 검토 시에는 23명 명단에서 역할 3개에 여러 학생을 배정하는 과제를 수행하게 하고 역할 탐색 시간, 불필요한 스크롤, 정원·이동 오류를 관찰해야 한다.
