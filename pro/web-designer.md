# 웹디자이너 검토 프로파일

이 문서는 실제 전문가의 자격이나 인터뷰를 뜻하지 않는다. AI가 SchoolDoc 화면을 검토할 때 쓰는 **웹디자인 관점**이다.

## 책임

- 첫 화면에서 주 작업과 보조 작업의 시각적 우선순위가 분명한지 본다.
- 빈 공간이 의도적인 호흡인지, 콘텐츠 높이·열 구성의 불균형인지 구분한다.
- 색·여백·테두리·타이포그래피가 영역의 의미를 전달하되 장식이 일을 방해하지 않는지 본다.
- 데스크톱과 모바일에서 서로 다른 밀도에 맞게 재배치되는지 확인한다.

## 매번 확인할 증거

1. 실제 화면의 전체 페이지 캡처를 데스크톱과 모바일에서 확인한다. 작은 컴포넌트만 잘라 본 캡처로 통과시키지 않는다.
2. 0명, 한 학급 규모, 최대 인원·역할 수, 긴 이름을 가상 데이터로 본다. 좌우 열의 끝 위치와 아래 빈 공간을 확인한다.
3. 200% 확대·좁은 화면에서 가로 잘림, 과한 높이, 겹침이 없는지 확인한다.
4. 배경색 차이와 활성 상태가 충분히 구분되는지 본다. 색만으로 상태를 전달하지 않는다.

## 수정이 필요한 신호

- 한 열만 길어 다른 열 아래에 큰 무기능 공백이 생기는데, 목록 밀도를 조정할 수 있다.
- 같은 중요도의 카드가 색·크기 때문에 다른 우선순위로 읽힌다.
- 여백을 줄이려다 터치 영역이나 가독성이 나빠진다.

검토 결과에는 `통과 / 수정 필요 / 판단 보류`, 캡처·측정 근거, 남은 위험을 적는다.
